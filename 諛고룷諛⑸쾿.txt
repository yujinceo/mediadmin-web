메디행정톡 인터넷 배포 방법 (Streamlit Community Cloud, 무료)
================================================================
이 폴더에는 API 키가 들어 있지 않아요. 그래서 깃허브에 올려도 안전해요.

1. github.com 가입 → 오른쪽 위 [+] → New repository
   - 이름: mediadmin-web / Public 선택 → Create repository
2. "uploading an existing file" 클릭 → 이 폴더 안의 것 전부(app.py, requirements.txt, packages.txt, .gitignore,
   배포방법.txt, .streamlit 폴더)를 끌어다 놓기 → Commit changes
   ※ packages.txt = 서버에 '자동 가림'용 글자 인식기(Tesseract + 한국어)를 설치하라는 파일이에요. 꼭 올려야 해요.
3. share.streamlit.io 접속 → GitHub 계정으로 로그인 → Create app
   - Repository: 방금 만든 mediadmin-web
   - Branch: main / Main file path: app.py
4. Advanced settings → Secrets 칸에 아래처럼 붙여넣기 (따옴표 필수)
     DATA_GO_KR_KEY = "공공데이터포털 인증키"
     ANTHROPIC_API_KEY = "sk-ant-로 시작하는 Claude 키"
5. Deploy 클릭 → 몇 분 뒤 https://○○○.streamlit.app 주소가 생겨요
6. 휴대폰에서 그 주소를 열고
   - 아이폰(사파리): 공유 버튼 → 홈 화면에 추가
   - 안드로이드(크롬): ⋮ 메뉴 → 홈 화면에 추가
   → 앱처럼 아이콘이 생겨요

※ 키를 바꾸고 싶으면 Streamlit Cloud 앱 화면 → Settings → Secrets에서 수정하면 돼요.
※ 무료 앱은 한동안 아무도 안 쓰면 잠들어요. 다시 열면 "깨우기" 버튼을 누르고 1분쯤 기다리면 돼요. 발표 직전에 미리 한 번 열어 두세요.

※ 인터넷 배포 버전(app.py)은 기록을 '브라우저 창'에만 임시 저장해요 (STORAGE = "session").
   여러 사람이 같은 주소로 접속하기 때문에, 서버 파일에 저장하면 다른 사람 기록이 섞여 보이기 때문이에요.
   창을 닫으면 기록이 사라지니, 시연할 때는 [내 진료비 기록] → [예시 기록으로 둘러보기]를 누르면 돼요.
※ .streamlit 폴더(파란색 디자인 설정)도 깃허브에 같이 올려야 해요. 폴더째 끌어다 놓으면 됩니다.
